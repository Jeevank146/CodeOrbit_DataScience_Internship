# CodeOrbit Tech – Data Science Internship

## Task 1: Data Cleaning & Exploration with Pandas

This project is part of my Data Science Internship at CodeOrbit Tech.

### Dataset Overview

The dataset was loaded using Pandas and analyzed for its structure, data types, missing values, and duplicate records.

### Technologies Used

- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook

### Cleaning Steps Applied

1. Loaded the CSV dataset using Pandas.
2. Checked the number of rows and columns.
3. Checked column names and data types.
4. Identified missing values.
5. Filled missing values in categorical columns using the mode.
6. Filled missing values in numerical columns using the median.
7. Identified and removed duplicate rows.
8. Calculated basic statistics including mean and median.
9. Analyzed value counts for categorical columns.
10. Saved the cleaned dataset as `cleaned_data.csv`.

### Final Result

The cleaned dataset contains **1032 rows** with no missing values and no duplicate rows.

### Files Included

- `Task_1.ipynb` – Complete Python notebook containing the data cleaning and exploration process.
- `cleaned_data.csv` – Final cleaned dataset.
